# Projeto MeuNegocio360 - Documento de Requisitos

## Frontend
- Stack Utilizada: React JS com Vite
- Paleta de Cores: Devem ser definidos como estilos globais da aplicação:

    - Laranja: #EC4E26 (Botões Primários, Barra de Navegação e texto de botões com onHover e secundários)
    - Creme: #fcf5f0 (Fundo da aplicação e cards)
    - Cinza: #3e3c3b (linhas das tabelas, Textos secundários e bordas dos cards)
    - Preto: #1f1612 (Texto Principal)
    - Beje: #cdbbae (Footer)

- Fonte: 
    - Barlow Condensend (pesos 500, 600 e 700): para títulos
    - Barlow (pesos 400, 500 e 600): para textos, tabelas e footers.
